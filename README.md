# ระบบตรวจสอบมหาเทพ
## GPS SECURITY TESTING PLATFORM

**ชื่อรุ่นเป้าหมาย:** ระบบตรวจสอบมหาเทพ v1.0

ชุดทดสอบ Android สำหรับสร้างข้อมูลตำแหน่ง GPS จำลองและตรวจสอบความผิดปกติของข้อมูลในแอปที่ผู้พัฒนาเป็นเจ้าของหรือได้รับอนุญาตให้ทดสอบ

### แอปภายในชุด

- **มหาเทพ LAB** — จำลองเส้นทาง GPS ต่อเนื่อง ปรับความเร็วและข้อมูลตำแหน่ง และสร้างกรณีทดสอบทั้งปกติและผิดปกติ
- **มหาเทพ AUDITOR** — รับข้อมูลทดสอบจาก LAB ตรวจสอบแพ็กเก็ต ประเมินความผิดปกติ และแสดงผลการตรวจสอบ

### สถานะรุ่น v1.0

v1.0 เป็นเป้าหมายการส่งมอบเมื่อการทดสอบ การรับส่งข้อมูลระหว่างสองแอป และการสร้าง APK ผ่านเกณฑ์ครบถ้วนแล้ว การเปลี่ยนชื่อไม่ได้หมายความว่ารุ่นพร้อมติดตั้งโดยอัตโนมัติ

### ขอบเขตการทดสอบ

ออกแบบสำหรับ Android test-location interfaces และการทดสอบระบบของผู้พัฒนาเองหรือระบบที่ได้รับอนุญาต ไม่ได้ออกแบบเพื่อซ่อนการจำลองตำแหน่งหรือหลบเลี่ยงระบบป้องกันของแอปบุคคลที่สาม
